# Vice Cover Studio

Turn any photo into a multi-panel GTA-style cover poster. An offline web app: upload a photo, pick one of 4 layouts and 5 Vice City sunset/neon grades, edit the caption, crop and position the shot, then export a PNG at 1080x1080, 1080x1350, or 1920x1080. Ships with 3 built-in sample scenes drawn in code. All art is original — no Rockstar assets.

Entered on [make.fun](https://make.fun/bounty/gta6-cover-art-01)

## How it works

1. Upload a photo (or try a built-in sample scene).
2. Choose a layout and a grade, edit the caption, and crop/position the photo.
3. Export a PNG in the size you need.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open the built app in `out/app`.
